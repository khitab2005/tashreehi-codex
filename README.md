# تشريحي | Tashreehi

منصة تعليم تشريح مستقلة، مجانية ومفتوحة المصدر، بالعربية RTL والإنكليزية LTR. تطبيق فعلي بـNext.js App Router وReact Three Fiber، مع حفظ التفضيلات والتعلّم محلياً دون حساب أو مفاتيح API.

## التشغيل

يلزم Node.js 20.9 أو أحدث مع npm. استُخدم Node.js 24 أثناء التحقق.

```bash
npm install
npm run dev
```

افتح <http://127.0.0.1:4317>. المنفذ مستقل عن المشاريع الأخرى، والخادم محلي فقط. لتغييره:

```bash
npm run dev -- --port 4320
```

لنسخة الإنتاج:

```bash
npm run build
npm start
```

لا تحتاج إلى `.env` أو قاعدة بيانات أو خدمة مدفوعة. إذا كان `node` متاحاً لكن npm غير مضاف إلى PATH على جهاز Windows الحالي، استخدم المساعد المحلي:

```powershell
.\scripts\npm-local.ps1 install
.\scripts\npm-local.ps1 run dev
```

المساعد ينزّل npm الرسمي إلى `.tools` داخل هذا المشروع فقط عند الحاجة. لا يعدّل PATH أو أي مشروع آخر.

## ما الذي يوجد فعلاً؟

- 12 ملف GLB محلياً، و194 عقدة Mesh، من Human Reference Atlas / HuBMAP، بترخيص CC BY 4.0. افحص العدد والبصمات عبر `npm run assets:verify`.
- ثمانية أجهزة **جزئية**: الركبة اليسرى، عضلة المستقيمة الفخذية ووتر الرباعية، النخاع الشوكي، القلب، الرئتان والمجاري المركزية، الكبد والبنكرياس والمرارة، الكُلية اليسرى والمثانة، الرحم والمبيض الأيسر.
- 25 بطاقة عربية وإنكليزية مرتبطة بأسماء عقد حقيقية، وبمصادر OpenStax. هذه ملخصات تعليمية أولية تنتظر مراجعة اختصاصي مستقل.
- دوران وتقريب وتحريك، اختيار بالأشعة raycasting، تمييز، عزل، إخفاء وإظهار، عتامة، مرشحات لأنواع الأنسجة، زوايا أمامية وخلفية وجانبية، ولقطة PNG مع الاعتماد.
- بحث ثنائي اللغة يراعي التشكيل العربي، مفضلة، بطاقات مراجعة، تقدم محلي، آخر درس، خمسة أسئلة MCQ مع شرح، وتدريب تحديد حجرة في القلب.
- صفحات رئيسية ومستكشف وأجهزة ودروس واختبارات ومفضلة وحول واعتمادات وخصوصية.

**ليست هذه نسخة كاملة من تشريح الجسم**. لا يوجد جسم موحّد أو أجهزة كاملة أو أدوات قطع أو محاكاة فسيولوجية. أجزاء المرجع التي ليس لها بطاقة عربية تُعرض صراحةً كبنية مرجعية غير مترجمة، دون اختلاق شرح لها. لا يُستخدم نموذج تجاري أو مجسم تخطيطي على أنه تشريح حقيقي. راجع [FEATURES.md](FEATURES.md).

## البنية

```text
src/app/                  صفحات App Router وCSS والمظهر
src/components/pages.tsx  واجهة التعلّم والمستكشف
src/components/viewer.tsx تحميل GLB/GLTF، WebGL، الكاميرا والاختيار
src/components/ui/        Button بنمط shadcn/ui وRadix Slot
src/lib/content.ts        أنواع المصطلحات وبيانات المحتوى والمراجع والاختبارات
src/lib/store.ts          Zustand + localStorage مع معالجة منع التخزين
public/models/            الأصول الفعلية وسجل المصادر والبصمات والترخيص
public/sw.js              PWA cache لملفات الموقع والصفحات التي تمت زيارتها
tests/unit/               تحقق البيانات والمنطق والتقدم
tests/e2e/                Playwright للكمبيوتر وAndroid وiPhone بالمحاكاة
```

يحمل المصطلح `id`, `name.ar`, `name.en`, `system`, `model`, `description`, `function`, `relatedStructures`, `modelNodeIds`, `source`, `note`. إضافة مصطلح تتطلب مطابقة عقده مع `public/models/manifest.json`؛ اختبار الوحدات يرفض العقد غير الموجودة. لا يتيح التطبيق رفع ملفات المستخدم؛ يدعم المحمّل صيغتي GLB/GLTF للأصول المراجعة التي يضيفها المطور.

## PWA والعمل دون اتصال

يُسجل Service Worker في **الإنتاج فقط**. استخدم `npm run build` ثم `npm start`، وافتح التطبيق مرة عبر HTTPS أو localhost. في Android استخدم قائمة المتصفح ثم «تثبيت/إضافة للشاشة الرئيسية». في iPhone افتح Safari ثم مشاركة ثم «إضافة إلى الشاشة الرئيسية».

تُحفظ الملفات والنماذج عند زيارتها؛ لا يُحمّل الأطلس كاملاً مقدماً. الصفحات غير المزارة تعرض شاشة offline واضحة. قد يحذف النظام ذاكرة الملفات عند نقص المساحة. ليست هناك مزامنة بين الأجهزة، وحذف بيانات المتصفح يحذف التقدم. تحديث المحتوى يستلزم زيادة إصدار cache في `public/sw.js`.

## الأداء وإمكانية الوصول

تحميل ديناميكي للعارض، نموذج واحد لكل عارض، مؤشر تحميل تدفقي، DPR لا يتجاوز 1.5، رسم عند الحاجة، دون ظلال أو postprocessing، تنظيف geometry/material وإلغاء fetch عند مغادرة النموذج. وضع الأداء يخفض DPR إلى 1 ويلغي antialias والديمبنج. اختيار البنى متاح من أزرار قابلة للوصول بلوحة المفاتيح، مع skip link وتسميات واضحة واحترام reduced motion. الملفات المحلية لا تعتمد على CDN وقت الاستخدام.

أكبر نموذج هو الرئتان، قرابة 10.7 MiB. لا تتوفر حالياً نسخ هندسية متعددة الدقة أو فك ترميز تدريجي للهندسة. مؤشر التحميل لا يعني أن الهندسة تظهر قبل اكتمال الملف. **لم يُنفذ قياس ميداني لـCore Web Vitals**؛ لا نفترض نتائج Lighthouse أو أداء الهواتف الفعلية.

## النشر على Vercel أو Render

المشروع جاهز لاستيراد المستودع المستقل. **تجهيز النشر لا يعني أن النشر تم.**

Vercel: اختر المستودع، Framework = Next.js، أمر البناء `npm run build`، إعدادات الإخراج الافتراضية. لا متغيرات سرية مطلوبة. يخدم Vercel التطبيق عبر HTTPS ويتيح تسجيل PWA.

Render: استخدم Web Service بنظام Node، Build = `npm ci && npm run build`، Start = `node node_modules/next/dist/bin/next start --hostname 0.0.0.0 --port $PORT`. يوجد [render.yaml](render.yaml) كإعداد مقترح لخطة مجانية إن كانت متاحة في حسابك؛ تحقّق من سياسة المزوّد الحالية قبل النشر. الخادم المحلي يبقى 127.0.0.1.

## الخصوصية والأمان

دون حساب أو دفع أو تحليلات أو استدعاءات AI. لا تُرسل التفضيلات إلى الخادم. CSP يمنع الموارد الخارجية وiframes وobject، مع `unsafe-inline` الضروري لمخرجات Next الافتراضية؛ لا يشمل التطبيق تحرير HTML أو `dangerouslySetInnerHTML`. توجد ترويسات nosniff وDENY وReferrer Policy وتعطيل إذونات الكاميرا والمايك والموقع. لا توجد بيانات مرضى. الروابط المرجعية تخضع لسياسات المواقع الخارجية، وقد يحفظ مزود الاستضافة سجلات تقنية.

لا تستخدم هذا المحتوى للتشخيص أو العلاج.
